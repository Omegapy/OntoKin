## Current development baseline

OntoKin's [GOAL](GOAL.md) is an AI-agent language for editable meaningful 3D objects, animation and simulation through authoritative `.ok` source. Finite increments do not complete that mission.

Complete feature release and full-product acceptance remain false. Read the [adopted inputs](docs/language-design/keyed-rekey-v0.1/README.md), [.19 Agent guide](docs/language-design/agent-v0.19/README.md), [engineering record](docs/engineering/keyed-rekey-2026-11-01-c086/README.md), [validation summary](docs/engineering/keyed-rekey-2026-11-01-c086/VALIDATION-SUMMARY.json) and [integration record](docs/engineering/keyed-rekey-2026-11-01-c086/integration.json).

`rekey_keyed<T>(input, (old_key, value) -> new_key)` preserves exact immutable payloads while computing stable keys. Unknown-binder static checking precedes dynamic input work, including for empty input. Complete input admission occurs once; callbacks visit old canonical keys once, at most 256 entries. Invalid keys and the first collision are refused deterministically before later callbacks. Successful output sorts by new key, with actual shared-ledger charges and cancellation checkpoints. Changed keys change generated occurrence identities; original payload entries, dependencies, taints and inherited contributor keys remain exact. Explicit finite maps and conditional String literals are supported; general String concatenation is not added. Renaming creates no physical or motion authority.
