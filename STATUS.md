# OntoKin status

## Current development baseline

OntoKin's [GOAL](GOAL.md) is an AI-agent language for editable meaningful 3D objects, animation and simulation through authoritative `.ok` source. Finite increments do not complete that mission.

**C081 pure keyed construction transforms are integrated experimental development through [PR #80](https://github.com/Omegapy/OntoKin/pull/80).** The explicit bindings are source `0.14` / `keyed-transform-0.1`, Agent/0.14 and recorded GLB/0.14; immutable bundle/files remain `0.2`. Complete feature release and full-product acceptance remain false. See the [adoption and frozen language inputs](docs/language-design/keyed-transform-v0.1/README.md), [.14 Agent guide](docs/language-design/agent-v0.14/README.md), [engineering record](docs/engineering/keyed-transform-2026-10-31-c081/README.md), [validation summary](docs/engineering/keyed-transform-2026-10-31-c081/VALIDATION-SUMMARY.json) and [integration record](docs/engineering/keyed-transform-2026-10-31-c081/integration.json).

`map_keyed<Out>(input, (key, value) -> body)` produces one pure value per existing key. It preserves exact keys/count/ASCII order, admits the 24 adopted immutable leaf families and keeps the 256-entry bound. Typed body-local binders, empty-body static checking, source derivations, scoped repair authority and all inherited type/unit/frame rules remain explicit. Every actual selection/binding/body/copy/materialization is metered. Map results are not memoized. The operation creates no mass, body, connection, event or motion authority; filtering, new keys, reduction and mutation are outside this increment. Older declaring units and default entry points retain their meanings.
