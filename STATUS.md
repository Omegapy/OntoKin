# OntoKin status

## Current development baseline

OntoKin's [GOAL](GOAL.md) is an AI-agent language for editable meaningful 3D objects, animation and simulation through authoritative `.ok` source. Finite increments do not complete that mission.

**C083 pure keyed filtering is integrated experimental development through [PR #82](https://github.com/Omegapy/OntoKin/pull/82).** Explicit bindings are source `0.16` / `keyed-filter-0.1`, Agent/0.16 and recorded GLB/0.16; immutable bundle/files remain `0.2`. Complete feature release and full-product acceptance remain false. See the [adopted language inputs](docs/language-design/keyed-filter-v0.1/README.md), [.16 Agent guide](docs/language-design/agent-v0.16/README.md), [engineering record](docs/engineering/keyed-filter-2026-10-31-c083/README.md), [validation summary](docs/engineering/keyed-filter-2026-10-31-c083/VALIDATION-SUMMARY.json) and [integration record](docs/engineering/keyed-filter-2026-10-31-c083/integration.json).

`filter_keyed<T>(input, (key, value) -> predicate)` selects entries from an exact `Keyed<T>` using a strict Boolean predicate. It evaluates and admits the input once, visits at most 256 entries in canonical ASCII order, and preserves surviving keys and detached values across the 24 adopted immutable leaf families. Empty input still receives static predicate checking with masked enclosing payloads and executes no predicates. Actual dependencies, taints and inherited map/reduction origins survive even when every entry is dropped. Detached `derived_filters` and generated `input_filters` preserve source repair authority. Every admitted operation shares current work accounting and cancellation; filtering creates no physical or motion authority.
