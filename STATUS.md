# OntoKin status

## Current development baseline

OntoKin's [GOAL](GOAL.md) is an AI-agent language for editable meaningful 3D objects, animation and simulation through authoritative `.ok` source. Finite increments do not complete that mission.

**C085 bounded pure keyed pair transformation is integrated experimental development through [PR #84](https://github.com/Omegapy/OntoKin/pull/84).** Explicit bindings are source `0.18` / `keyed-zip-0.1`, Agent/0.18 and recorded GLB/0.18; immutable bundle/files remain `0.2`. Complete feature release and full-product acceptance remain false. See the [adopted inputs](docs/language-design/keyed-zip-v0.1/README.md), [.18 Agent guide](docs/language-design/agent-v0.18/README.md), [engineering record](docs/engineering/keyed-zip-2026-11-01-c085/README.md), [validation summary](docs/engineering/keyed-zip-2026-11-01-c085/VALIDATION-SUMMARY.json) and [integration record](docs/engineering/keyed-zip-2026-11-01-c085/integration.json).

`zip_keyed<T,U,V>(left, right, (key, left_value, right_value) -> body)` pairs exact complete key sets across the 24 adopted immutable leaf families. Static checking precedes dynamic work, including the callback with unknown binders. The left is evaluated/admitted once, then the right once; a missing partner is refused before any callback. Successful callbacks execute once per canonical key, with at most 256 entries. Detached results preserve both operands' actual dependencies, taints and contributor-specific origins. Shared budgets and actual cancellation checkpoints apply. Pairing creates no physical or motion authority.
