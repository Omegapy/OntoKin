# C086 independent keyed-renaming inputs

This corpus contains 177 core cases: 118 valid constructions with separately authored explicit .18 controls, and 59 intended refusals. The separate [Agent inputs](agent/workflows.json) add four delivered states with literal .18 controls and three refusals. The [source expectations](expected.json), [key contract](../../docs/language-design/keyed-rekey-v0.1/contract-details.json), [Agent geometry](agent/geometry-expectations.json), [delivery allowances](agent/delivery-comparison.json) and [byte adversaries](agent/supplied-byte-adversaries.json) are predetermined inputs. Counts are not C086 execution results.

The core covers every one of the 24 inherited immutable leaf families in empty, identity and renamed forms, plus ordering/cardinality, key spelling, collisions, static/dynamic precedence, exact types, malformed syntax, pure cycles/access, declaring versions/pins, aliases, taints, image closure and nested/current/inherited origins. A separate token scanner checked full spans, grouped first tokens, binder names, source/revision identities and UTF-8 coordinates without production parser/runtime imports. Expected outputs come from literal payloads, authored name mappings and source mathematics. The explicit .18 controls provide a separate unchanged-language comparison.

`expected.json` retains its original preparation labels and pending-checklist text byte for byte. [ADOPTION-DECISION.json](../../docs/language-design/keyed-rekey-v0.1/ADOPTION-DECISION.json) records which preparation conditions were actually completed and which runtime/delivery obligations remain open. A historical preparation label is not the adopted or executed state.

The initial baseline preflight passed 117/118 core controls and all four .18 delivery controls. The one failure belonged to the literal control for guarded-helper-replay: unused members referred to a helper intentionally omitted from that control. A separate root review approved removing only those unused control members. All .19 source bytes, intended payloads and other controls remained unchanged. The separately named second preflight passed all 118 core controls and all four complete .18 delivery controls. Both runs retained exact clean C085 source identities and all 7,446 file/mode hashes before and after. The original failure and corrected lineage remain in the preparation evidence.

The Agent scenario renames only first.panels["left"] to first.panels["front.left"], preserving its original payload and the right panel, sibling occurrence, libraries, exact PNG and moving marker. The corresponding .18 controls intentionally cover only their four named authored states; their literal branches are not a general evaluator for arbitrary name maps. Duplicate output keys must reject the candidate atomically. Every delivered state needs exact BIN/raw-JSON/framing comparison after narrowly validated metadata changes, native readers and direct capture review.

`agent/` manifests resolve paths relative to that subdirectory; core manifests resolve paths relative to this directory. All paths are ordinary files, and every required asset is included. The exact file manifest in INPUT-FREEZE.json must be published and read back before runtime work.
