# Polygon lofts with authored section frames

These inputs and mathematical expectations are fixed before C078 runtime implementation. They select source `0.11` / `framed-polygon-loft-0.1`, Agent/0.11 and recorded GLB/0.11 under [OK-LANG-011](../../docs/language-design/framed-polygon-loft-v0.1/ADOPTION.md). A frozen expected outcome is a requirement, not an executed product result.

Each section explicitly supplies a rigid pose in its carrier's local frame. Corresponding ring and vertex identities determine the prescribed strip triangles. The sections do not describe a continuously swept surface. Positive cases include identity equivalence to the .10 contract, exact cyclic and Y90 rotations, a bent solid, hollow elbow, solid and hollow handles, concavity, multiple holes, material changes, declaration reordering, a near-half-turn with valid forward progression, and a rounded nonplanar cap.

The two count maxima reach 256 authored vertices, eight holes per section, 540 triangles and 1,620 flat corners. Their entry source requests 2,000,000 operations and 80,000 ms, which the execution host must independently authorize. The over-limit count negatives use the same request. Other cases omit requests and preserve the ordinary 100,000-operation / 30,000-ms defaults. None of these predetermined settings is evidence of measured execution.

`identity-solid-legacy.ok` and `identity-hollow-legacy.ok` are new .10 comparison sources. They do not replace or change any historical fixture. Compare actual decoded geometry with their .11 counterparts while retaining each source revision and format identity.

`parts.ok` defines a pinned reusable elbow component. Each occurrence constructs poses with its own `self.frame`. `assembly.ok` instantiates a moving first occurrence and a stationary sibling. An invalid edit changes the first occurrence's `end_x` from 4 to -1 meters and must roll back. The accepted repair changes only that source value from 4 to 5 meters. The corresponding final section's origin moves in local X; its orientation and all ring identities remain unchanged. The sibling and exact library bytes remain unchanged. `generated.ok` creates three keyed components with different rises under one moving parent.

The free-function cases pass an owning `Pose` into a section constructor and pass framed sections into a separate geometry function. They distinguish legitimate same-carrier reuse from a section escaping one occurrence and being consumed by another. A free function has no lexical `self`; the consuming owner must remain an explicit validation context.

`expected.json` contains authored frames, independently canonicalized wxyz leaves, original XY rings, exact single-round source positions in decimal and hexadecimal notation, exact progression comparisons, triangle counts, material ownership, independently measured area and signed volume, analytic controls, motion samples and exact repair strings. The source quaternion normalization is evaluated with Decimal at two precisions that must agree. The adopted matrix and completed coordinates use Fraction arithmetic. There is no product import or product request.

For convex quadrilateral endpoints, the independently specified diagonal is v0-v2. Other endpoint measurements use an oriented boundary integral after checking exact planarity. That integral measures area and signed volume; it is not emitted cap triangulation or a replacement for complete cap coverage checks. The nonplanar case measures its two explicit endpoint triangles in three dimensions and retains the original XY domain for coverage.

Invalid inputs exercise frame ownership, types and units, quaternion admission, origin bounds, section counts and orders, exact separation and progression, correspondence, inherited ring rules, missing materials, strip pinches, collapsed identities, rounded cap collapse and nonadjacent contact. Three source-valid precision controls require geometric delivery refusal, including clearance after a section rotation and after separate outer visual placement. Resource refusal does not satisfy those expectations.

An independent destination checker must verify original XY cap coverage by source identity; exact transformed vertices and prescribed strips; complete opposite edge incidence; only intended shared-vertex or shared-edge contacts; actual outward normals, cap orientation, materials, area, positive signed volume and carrier motion. Counts, positive volume or an image alone are insufficient. Reordering equivalence does not promise byte-identical GLBs because source provenance changes.

`acceptance-freeze.json` binds every source, expectation, authoring note and generator by size and SHA256, and binds the actual adopted decision. Preserve it after publication. A later input correction needs a new identified record with its independent cause; a runtime failure is not authority to regenerate a favorable expected result.
