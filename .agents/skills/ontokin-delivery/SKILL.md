# Deliver one OntoKin milestone

Required sources: [AGENTS](../../../AGENTS.md), [ROLE](../../../ROLE.md),
[PROTOCOL](../../../docs/workflow/PROTOCOL.md), [HANDOFF](../../../docs/workflow/HANDOFF.md).
Read missing applicable text fully; do not reread unchanged copies. The session's explicit
[mode](../../../AGENTS.md#execution-modes) selects between marked rules.

## Define and implement the work

Apply PROTOCOL sections 3–4 in full. Return design defects to the Director; never
silently reduce acceptance.

## Verify the candidate

Apply PROTOCOL section 5 and AGENTS' change-specific checks on the mode's explicitly
selected executor; resolve mandatory review findings using actual current
artifacts/evidence.

## Integrate and verify actual main

Apply PROTOCOL section 7, including its adopted policy; distinguish integration,
release acceptance and unresolved gates.

## Close and hand off

Apply [ontokin-learning](../ontokin-learning/SKILL.md); record capture/skip rationale.
Verify published checkpoint and branch/ownership disposition.

- **Local:** close under [HANDOFF's local section](../../../docs/workflow/HANDOFF.md#local-sessions):
  source checkpoint, truthful task and session record, verified push state when online,
  durable evidence. An archival ZIP is optional unless the selected task requires one.
- **Browser:** HANDOFF saved ZIP/external receipt. Stop after declared phase; merged
  code/documentation cannot replace delivery.
