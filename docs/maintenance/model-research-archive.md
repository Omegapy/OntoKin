# Archived model research

OntoKin's C170–C174 experiments used Solv3R to reconstruct a scene and FlowHMR to estimate human motion. On November 9, 2026, the owner deferred this work until the project has a suitable persistent environment. Language development continues from the C169 implementation on GitHub `main`.

The greenhouse video yielded a 2D track of one person across all 300 analysis frames. The fresh 3D motion and its root-translation and left-knee fits were never produced. The last Runpod command was a no-charge preview.

Revisit the experiment only if the owner chooses to reopen it and provides a suitable persistent environment. The recorded capture procedure requires a CUDA worker and authorized SAM 3D Body and neutral SMPL-H files. Any paid compute or storage requires a separate decision from the owner.
