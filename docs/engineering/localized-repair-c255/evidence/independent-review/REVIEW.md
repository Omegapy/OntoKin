## Findings resolved before approval

1. The initial semantic graph gave implicit origins an empty interface and an
   abbreviated identity. The adopted core contract requires `rigid.origin`; the
   preserved stable key includes `@system/origin`. All 18 origins were corrected.
2. The scene identity included an invented third key. It now retains the two
   authored module/scene keys.
3. Root review identified a raw-matrix rotation that exceeded the original
   angular bound while fitting inside the separate decomposition residual. An
   independent raw-angle predicate was added.
4. Further independent execution found two remaining false acceptances in that
   predicate: a near-rigid raw matrix's permitted scaling residue biased a
   trace-based angle downward. For delivery, a quaternion at .001 rad paired
   with `1.0000005 * Rz(.0010000001)` falsely passed. An analogous reference
   example falsely passed at the 1e-9 rad limit. The correction derives the proper
   rotation through a bounded polar factor only after the unchanged scale/shear
   guards pass. It then applies the original angular limit independently. Both
   retained failures now reject, and inside-limit residual controls still pass.
   No angle or structural tolerance was widened.
5. Blank and control-character origin references now fail. Native path resolution
   itself remains an explicit future reader obligation.

The initial false-acceptance record is retained separately from the successful
rerun. Its note discloses that the probe's original default output was overwritten
when rerun and that its exact observed values were reconstructed from the retained
tool output. The source SHA and failing values are preserved.

## Scope limits

A passing component result remains `realTrialSuccess: null`, with
`executionAllowed: false` and `artifactReaderQualified: false`. Synthetic control
artifact bytes and matching origin labels establish internal consistency only.
They cannot establish that a reader traversed an actual artifact, that an external
harness authenticated a revision decision, that no invalid state was ever
promoted, or that a claimed clean rebuild occurred. Those are separate gates.

The checker is restricted to this exact two-file OntoKin source closure and its
finite primitive contract. Direct-route decoders, native baseline seeds, arbitrary
tessellations, normal fidelity, all-time motion, runner/model admission and
comparative advantage remain unqualified. The public one-family corpus is still
ineligible for an advantage claim.
