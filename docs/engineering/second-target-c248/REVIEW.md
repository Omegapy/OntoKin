## Meaning and limits

The Python model composes unchanged C247 model code and its synthetic completed
receipt provider. It does not run C246 callbacks, parse GDScript or prove native
getters, installed storage, lifetime or precision. Pinned source supports the
finite import route and storage label; installed build lineage is unresolved.
Two equal reads detect lasting changes but do not establish atomic capture.
Bounded loops do not enforce hard native process, allocation or time limits.

Godot/version/parser/import/render/save/reopen, source export, fixture
regeneration, C234 comparison, product and aggregate execution remain unrun.
`execution_admission` and `native_acceptance` remain false; R07 remains pending.
The held draft is based on unchanged C247; main integration is outside this
scope. Animation observations, serialization, raw sealing, diagnostics, useful
images, persistence, launcher and reservation remain separate gates. Original
failures, including the strict Blender-normal failure, retain their meanings.

After the verified successor handoff is confirmed saved, stop. The separately
