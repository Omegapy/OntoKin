## Preserved corrections

C249-F01 affected initial native source
`b2b8f98b2270df607a04c87536e7d6f44316b3bc`: it resolved the player's root path before
checking for an unsupported absolute path. The pinned resolver can diagnose
absolute lookup outside the scene tree. The corrected source records and
validates the path first, then resolves only an admitted path. Original source
and the independent finding remain preserved.

C249-F02 affected the initial synthetic model, not native source: strict metadata
conversion across every player setting let malformed simulated values escape
as exceptions. The correction captures settings incrementally, preserves raw
scalar values for their actual supported-value checks, and turns a failed queue
metadata conversion into a returned partial refusal. The independent original
exception evidence is preserved; no earlier failure is relabeled a pass.

The first author binding invocation used an inexact quoted native diagnostic
string. It failed its lexical assertion before returning a binding result.
The assertion was corrected to the exact pinned source wording and passed on
rerun. This was a checker error and did not require a product/source change.
The first eleven source transfers also had one transport-added trailing newline;
that extra byte was removed against the exact fetched string length before
pinning. Original retrieval metadata records the correction.

## What remains unproved

Godot parsing, native/version starts, actual callback/NodePath/getter behavior,
resource lifetime and installed lineage are untested. The sole-animation join is
source-supported and conditional; no public pointer attestation from GLTFAnimation
to the returned native Animation exists in this component. Key counts are
observations, not key payload or pose validation. The imported player is still
unassigned with its default active/idle settings. Disabling advancement belongs
to the later sampling component.

The synthetic model composes unchanged C248/C247 Python code and C247's fabricated
completed receipt provider. It does not execute C246 events, native codecs,
NodePath parsing, engine metadata or diagnostics. Repeated reads can reveal
lasting drift but cannot prove atomic capture. Native getter allocation, process
limits, raw sealing, serialization, rendering, persistence and full admission
remain open. R07 stays pending and the strict Blender-normal failure is unchanged.
