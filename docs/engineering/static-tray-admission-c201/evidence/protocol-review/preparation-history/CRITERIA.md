| State | Evidence required | Claim allowed |
| --- | --- | --- |

| Executable readiness | Actual committed coordinator/lock/transaction/readback code, applicable CPU controls, fresh host verification, complete executable closure and independent exact-input approval | Ready for the single identified bounded invocation |
| Admission result | Actual four-slot evidence, receiving/readback/control results, four visual reviews and independent final result review | Only the named finite admission outcome |

A preparation-only record must not say “protocol/coordinator prepared” when no
coordinator was implemented and verified. Use “C201 admission protocol prepared;
coordinator and execution gates pending.” A schedule ceiling is not present
permission to start a child process, and a `README` or JSON schema is not an
execution approval.

## Implementation gates that must remain pending

The inspected `qualification.py` requires twelve successful transactions,
receivers and readbacks. `lock.py` verifies the full twelve-slot cohort and
historical controls. `format_check.py` requires twelve readback slots and a
twelve-check ceiling. `transaction.py` uses that verifier and N01/N02 baseline
references. The Node probe also constrains the readback manifest schema.

Therefore a separate four-slot coordinator alone is insufficient. The eventual
C201 implementation needs reviewed lock, transaction, readback/probe compatibility,
explicit reference and result semantics. It must preserve qualified geometry,
source lowering, reader/receiver, supervisor/store and settings by exact identity,
or separately review an explicit changed role. A process-wide monkeypatch,
disabled historical guard or altered C200 ledger is not acceptable.

The preparation-only review must leave all of these gates open: executable
implementation; meaningful failure-path CPU controls on actual new code;
current dependency verification; committed complete input lock; independent
native-readiness approval; sole coordinator invocation; actual outputs and
receiving/readback results; actual delivered controls; four visual reviews;
and final independent admission review. The producer cannot create its own
approval. No fabricated lock hash, implementation SHA, process receipt or
pass count may fill a future field.
