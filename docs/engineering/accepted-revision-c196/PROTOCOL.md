# C196 accepted revision promotion

## Scope

This experiment continues the accepted C195 design. H is the preserved 375 mm
source (`2143515f358e36c1dd9a1deef83dba2519a99be6141b64d8bd9dae987761fbd0`).
G is C195's already accepted 365 mm repair
(`ba105a8ca6e9c19dfd06fabd7a06a2254c4ba14d76042dfa88ca365d5de6f7ee`).
No source editing, new author, new backend, tolerance change, fault injection,
or native retry is part of this qualification.

## Preparation and review

Restore C195's recorded archive using its unchanged portable replay. Require
its complete recorded audit to pass without native construction or receiving
execution. Restore each extracted file's original tar mode; then copy the
complete OntoKin accepted-run directory with its H store and ownership-error
receipt. Keep the original acceptance record, source, and complete artifact
closure. Freeze every file's SHA-256, size and mode, the exact initial state
bytes, the C195 archive, acceptance, readers, runtime and destination contracts,
the qualified Blender executable, this protocol and the execution program.

An independent reviewer must approve `INPUTS.json`, `PREPARATION.json`,
`EXECUTION-PLAN.json` and the execution script by SHA-256 before native work.
The coordinator supplies a separate, observed C195 integration receipt. The
runner refuses to execute if C195 has not merged or any frozen byte differs.

`EXECUTION.jsonl` is created exclusively once in this engineering record.
Each reserved operation is logged and flushed before execution. A second
invocation cannot reopen or replace it. A failure stops all remaining work;
the reached store, process receipts and diagnostics remain evidence. An
interrupted or failed attempt consumes its reservation. No automatic retry
or replacement attempt is permitted.

## Predetermined sequence

1. Invoke the unchanged `prototypes.guided_contact_v02` transaction interface
   once with exact G in the copied H store and `expected_revision=H`. Require
   success, commit, previous H and accepted G. The resulting state must point
   to a new artifact directory whose retained source, canonical input and
   manifest identify G and match the state's hashes.
2. Compare the entire accepted-run inventory before and after promotion.
   Every preexisting file must retain its bytes, size and mode except the
   intentionally replaced `store/state.json`. Enumerate every new file and
   directory, retain the exact original state separately and verify the old
   H source/artifact closure and recorded rejection remain intact. The
   unchanged transaction's sole commit point is its `os.replace` of state.
   C193 T15 supplies inherited publication-failure evidence; C196 adds no
   new crash or concurrency test.
3. Submit valid H against the now-G store with `expected_revision=H` once.
   Require `C193_E_STALE_REVISION`, publish phase, the actual source header
   span, failure and no commit. Both revision fields must remain G. Native
   substeps, elapsed time, result/log bytes and staged output bytes must all
   be zero. All prior store files and modes must remain unchanged. The only
   added file is `attempts/<attempt_id>/result.json`; no staging or artifact
   output is admitted. Ordinary static parsing work may be nonzero.
4. Resolve `state.json`, then its retained G `source.ok`, and read those exact
   bytes. Copy the bytes to a separate readback input location and perform
   one clean build in a fresh store. Do not use the prepared G path for this
   build. Require source identity G, successful commit and exact canonical
   input/native samples/raw GLB/final GLB equality with both the promotion
   and C195's accepted G. The promoted store remains unchanged.
5. Run the unchanged independent provenance and numerical readers on each
   new delivery, including all 481 samples, unrelated parts and the unchanged
   0.2 mm mapping limit. Reopen each new `.blend` independently once with the
   unchanged inspector. Require cache clearing, unchanged configuration,
   no reconstruction and exact agreement of all 481 native sample records.

Only one native promotion and one clean regeneration are reserved. Each uses
1,000,000 operations, 80,000 ms and a 100-second outer watchdog. Each saved-scene
replay has its own reservation and the unchanged inspector's 80-second outer
watchdog. There are at most two constructions and two replays, including
failures. The stale transaction is the sole new negative call and must not
schedule native work.

On an outer timeout or interruption, the runner stops its owned descendant
tree across process groups. Linux subreaping retains responsibility for native
workers that start a new session. Cleanup permits two seconds for termination
and three seconds for forced stopping and reaping, records every signal and
remaining process, and cannot convert a timed-out construction into a pass.
The pre-execution cleanup probe uses only synthetic Python processes; it is
supervision evidence, not a new product fault-injection or native trial.

## Receiving evidence reuse

For each new raw/final GLB, require byte equality with C195's `ok-repaired` G
delivery. Bind a receipt-to-artifact map to the exact C195 artifact identities,
Khronos and Three.js receipts, Blender import receipt, three reviewed PNGs,
visual acceptance, receiver scripts, dependency manifest/archive and selected
source/backend/destination contracts. Verify all original pass flags, hashes,
three poses and seven meshes. Reuse is inherited evidence, not a new receiving
execution or visual review. A changed artifact or incompatible binding stops
the experiment; no additional receiving job is authorized as a rescue.

Passing this sequence establishes this accepted-store H-to-G promotion,
rejection of the real formerly accepted H revision and regeneration through
the accepted pointer. It does not establish general contact, production
backends, comparative authoring benefit, live destination physics, crash
recovery, concurrent-writer reliability or full-product acceptance. Preserve
the inherited FAILED regression driver/tail, 4,239 distinct passes and thirteen
torque artifact-read methods NOT RUN.
