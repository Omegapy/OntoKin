standard library. It calculates original offsets from the actual entry/helper
source before opening GLB follow rows. `SOURCE-AUTHORITY.json` retains exact
adopted clauses; `SOURCE-BASELINE.json` retains byte witnesses and source-derived
identities/values. `ARTIFACT-BASELINE.json` records direct GLB JSON traversal,

Both endpoints independently contain eight follows. The first root uses three

The before/after length change does not change these source follow facts.

Each actual artifact follow row has exactly six observed fields: path, full
element ID, parent-frame path, child-object path, SI offset and WXYZ quaternion.
There is no direct artifact relation-definition table, follow declaration span
or separate offset-frame field. Source-derived values must retain that label.
The child class and its complete source mapping support association; they do
not create missing relation authority. All 18 GLB objects are scene roots, so
the glTF tree is not an alternative follow graph.

## Admission and authority boundaries

The finite source reader may refuse unsupported expressions, inheritance,
arbitrary reference traversal, sites-as-parent, non-self children and relevant
nested/per-key overrides. A successful partial observation does not certify
complete source validity. Every used dependency must nevertheless satisfy its
actual type, access rule, initializer scope and effective override precedence.
An unused unsupported expression must not provide a hidden default for a used
field. Ownership alone never supplies parent or child pose authority.

The raw artifact API reports untrusted claims. The comparison API must compare
complete relation sets and validate full occurrence/class/source/program
bindings. The bound API adds exact original byte/size admission; those hash
gates must not prevent deliberate raw-source and raw-artifact measurements.
Relevant duplicated child FrameRef/Vec3 property claims must agree if included
in the contract. Unchecked keyed property dumps, body/motion fields, sampled
geometry and the joint/follow authority union remain explicitly unqualified.

Core numeric rules combine a literal and exact unit factors before one canonical
binary64 rounding. Quaternion construction admits finite nonzero tuples within
1e-12 of unit norm, normalizes and canonicalizes the first nonzero sign; q and
-q denote the same orientation. The candidate's finite numeric implementation
and comparison allowance require a defensible bound or a clearly delimited
policy. The C255 formulas/tolerances are preserved, never imported as answers.

## Scoped executable controls after the candidate freezes

1. **Original traversal and origins.** Both endpoints; eight independently
   derived relations; every source byte witness reads the claimed exact token
   or declaration; every artifact pointer reaches an actual raw field. Check
   full child/class/definition associations and explicit absent relation fields.
2. **Lexical scope and defaults.** Original Rack self remains parent, never
   Finger self. Remove a supported initializer to observe actual world/zero
   class defaults; change default alone while initializer remains effective.
   Change enclosing direct input override and helper argument independently.
3. **Source-only change.** Supported parent, translation, rotation, relation
   name/key and keyed input edits must change observations before historical
   admission. Source/artifact comparison with old metadata must refuse.
4. **Artifact-only change.** Mutate an actual follow parent, child, identity,
   translation or rotation without modifying source. Raw measurement changes
   or explicitly refuses; comparison refuses. Do not read a producer sidecar.
5. **Coordinated changed input.** Independently construct updated metadata and
   source bindings for supported world-parent, offset or rotation changes.
   Agreement should pass raw comparison while strict historical admission
   refuses. Ownership must remain unchanged for a parent-only follow change.
6. **Identity and source association.** Stable member key versus display name;
   dotted literal key preservation; swapped/truncated/unknown child or relation
   IDs; mismatched class/definition IDs, source hashes, source spans, program
   manifest and entry/module claims. Matched relation text alone is insufficient.
7. **Multiplicity and graph.** Missing/empty/extra rows, duplicate full IDs,
   duplicate paths, conflicting rows, repeated incoming follows, self-cycle
   and multi-object cycle. Follow-only checks do not qualify the joint union.
8. **Field shape and repeated claims.** Missing required fields, extra relation
   fields, wrong scalar/list/object types and sizes, booleans used as numbers,
   malformed IDs/paths; typed child FrameRef/Vec3 copies absent, contradictory,
   wrong type or wrong unit metadata. Unobserved adjacent fields remain labeled.
9. **Frames.** Distinct parent and pose reference, world versus explicit frame,
   unknown frame and matching display prefixes with unequal full identities.
10. **Lengths and keyed values.** m/cm/mm equivalent values; signed values,
    canonical zero, helper sign/binder substitutions, wrong dimensions/types,
    unsupported arithmetic/calls, duplicate keys and duplicate assignments.
11. **Quaternions.** Nonidentity rotation, sign-equivalence, canonical sign,
    zero and invalid/nonfinite tuples, just inside/outside exact norm bounds,
    nonzero and zero component comparison limits, tiny/subnormal components,
    malformed lexemes and bounded exponent handling. Compare using an
    independent standard-library numeric reference, never a producer helper.
12. **Visibility and scope.** Public/private used parameters, missing relation
    visibility, module default-public behavior, predefined name shadowing,
    wrong declared FrameRef/Vec3 type, wrong helper parameter/return type and
    conflicting names/keys. Source order must not repair an invalid binding.
13. **Unsupported overrides.** Every used nested/per-key dependency override
    refuses; the original unrelated length override remains unobserved.
    Explicitly cover a same-name parameter in a different declaring class.
14. **Transport and resource refusals.** Invalid GLB header/chunk/JSON, duplicate
    JSON keys, malformed UTF-8, oversized source/artifact, token/nesting/key/
    relation/helper/expression/numeric-lexeme caps, cycles and public I/O errors.
