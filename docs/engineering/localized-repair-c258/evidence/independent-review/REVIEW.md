preserved in the baseline receipts.

producer sidecar. The implementation's declared pinned C257 lexical/identity

rotations, near-unit input, minimum subnormal components and midpoint ties.

## Original defect and correction

The first immutable implementation was commit
`85b2d309ac94e8f084fe275a198b7cd333b1ce0f`, reader SHA-256
`0e79f52b1a1b8468d261c0ded17eea35f2b973279880fe04892c41cf9c73633d`.
The first cohort passed 101 of 102 controls. It incorrectly admitted a user
parameter named `frame`, which conflicts with an implicit Object member.

Two additional targeted inputs confirmed the practical binding error. A Rack
parameter named `frame` was bypassed when a generated initializer read
`self.frame`. A Finger parameter named `origin`, typed as FrameRef and used by
both follow parent and pose frame, was accepted even though the inherited
`origin` field is a SiteRef. The accepted values came from a mistaken namespace
interpretation. These are one defect family, not three independent defects.

The corrected reader reserves the implicit Object member names for user
declarations and checks direct initializer targets and class field assignments.
Normal supported writable-field assignments and unrelated stable keys remain
distinct. The final cohort adds symmetric namespace/assignment controls,
including a valid relation whose stable key is `frame`, and rejects both
targeted used-binding failures. Original reader bytes, results and exact failed
source inputs remain preserved under `attempt-01` and `attempt-01-targeted`.

all property dumps, artifact physical/motion declarations, the joint/follow

native/model execution and comparative advantage remain outside this work.

checks justified by that change. No further optional test or feature is needed
to close this finite independent review.
