# Independent C256 review plan

The selected component reads 18 local meshes and 126 finite sampled transforms per historical C210 GLB. Full C255 semantic/rebuild/decision integration is outside this boundary. Review must not replace missing fields with expected answers or treat a partial observation as route qualification.

## Independent positive evidence

Decode actual GLB JSON and BIN chunks using only standard-library bytes/struct/math. Enumerate the 18 source identities from the pinned raw keyed-rack declarations; distinguish Rack, Finger and Blade definitions. Read positions, indices and time/output accessors with concrete offsets. Compare 252 before/after poses to C253's closed equations, and geometry to source dimensions/radius with the frozen delivered tolerances. Independently re-resolve all field origins and compare complete arrays to the candidate output. Keep the two artifacts' current hashes and two-file source closure separate from semantic correctness or authentic accepted-state history.

## Negative and metamorphic controls

- Structural: GLB magic/version/length, truncated JSON/BIN/chunk, duplicate keys, nonfinite literals, external buffers, invalid bufferViews/accessor extents/count/types/strides, out-of-range indices, malformed scenes/node references, invalid attributes or primitive profile.
- Identity: omitted/extra/duplicate stable ID, mutated root prefix or generated key, definition swap, node/program occurrence disagreement, source digest and program revision mismatch, source-span mismatch, legitimate display-name changes where admitted.
- Measurements: altered POSITION bytes with unchanged geometry metadata; altered metadata with unchanged bytes; changed translation and quaternion samples; zero/nonunit/nonfinite quaternion; scale/reflection/matrix override; changed animation target, duplicate channel, unsupported interpolation, missing time, duplicate/nonmonotone/out-of-range time samples.
- Origin and trust: concrete accessor/node/track references match actually measured elements, hash tracks modified bytes, sidecar cannot supply geometry/motion, output never asserts complete semantics/rebuild/acceptance/trial success.

Changed valid numeric inputs may be measured rather than rejected. Their output must reflect the bytes so independent frozen formulas can detect the error. Invalid or unsupported structures must refuse without a success-shaped result. Positive quaternion sign equivalence must retain the same orientation. A documented finite supported profile may refuse new structures instead of generalizing.

## Applicable integration checks

Run the new authored suite, independent probes, unchanged C255 31-method suite, C253 manifest verifier and documentation-preservation checker at the final candidate and relevant resulting-main revision. Verify executable inputs outside C256 remain unchanged. `tools/check_local.py` default unconditionally runs the entire inherited unittest cohort and six other source/Agent roles, with no affected-only selector. C255 NEXT-TASK's explicit reader/component gates govern this isolated scope; do not claim a full local-driver or aggregate-regression pass. Preserve previously recorded aggregate and native failures.

No model/native/destination launch, source rebuild, new asset family or full runner is part of this review. All scripts, attempts, findings and receipts stay in this audit directory; author-owned source is read-only to the reviewer.
