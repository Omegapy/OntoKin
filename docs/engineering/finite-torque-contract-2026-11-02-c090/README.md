## Adopted finite scope

A signed scalar external couple acts about positive world X, Y or Z on an
actually free homogeneous sphere. Its own canonical inertia supplies the law.
The axis remains latched through zero, cancellation and reversal. Exact
half-open intervals, ordered release/impulse interactions and complete boundary
rollback retain source authority. Canonical motion stays on the inherited route
until the first committed nonzero final acceleration, which may arise when a
cancelling interval completes. Separate rotation then preserves translation and
its existing numerical history.

Explicit new bindings are source `0.22` / `torque-0.1`, `ontokin.agent/0.22` and
recorded `ontokin.glb/0.22`. Source grammar, physical dimensions, import edges,
refusal precedence, rounding, bounded phase evaluation, reference/error
transport, real work charges and all twelve Agent operation shapes are fixed.
Earlier bindings, ordinary defaults, fixtures and release gates are unchanged.
