## Structural assessment

The observer derives ownership only from source containment. It retains UTF-8
byte origins and distinguishes occurrence identity from definition identity.
Class resolution follows the actual declaring module and visibility. It accepts
only the two supplied bounded source byte strings, binds the leaf import to its
actual hash, and derives the canonical manifest and program revision from them.
Generated collections add no intermediate object to the owner graph.

Raw artifact observations remain untrusted. Comparison checks every admitted
owner representation, full identity coverage, source spans, strict integer span
types, class identity and repeated source authority fields. The separate
historical entry point additionally requires the fixed original sizes and hashes.
No transform, follow, hinge or display-name field supplies an owner.

The implementation has finite source bytes, tokens, syntax depth, definitions,
literal keys, object expansion, identity components and GLB bytes. Historical
reads check exact sizes before reading at most one extra byte. The GLB reader
collects headers before checking that exactly two chunks exist, but each loop
advances at least eight bytes under a 4 MiB input cap. At most 524,286 zero-length
headers can be visited. This is finite; this review found no unbounded traversal
and did not expand the accepted format or add an unrelated parser requirement.

All imports are Python standard library modules. No product evaluator,
C255 expected semantics, C256 identity helper, external process, model or native
execution is invoked. Outputs explicitly withhold complete source validity,
complete C255 semantics, execution permission and trial qualification.
