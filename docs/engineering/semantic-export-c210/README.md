# C210 semantic export and constrained edit

**Status: implementation and verification in progress.** This is one finite proof of source-bound semantic transport using existing keyed-rack construction, Agent/0.2 and GLB/0.2. It does not establish a new destination integration or authoring advantage.

Read the [scope decision and staged roadmap](DECISION.md), [finite semantic contract](CONTRACT.md), [Unreal interoperability boundary](UNREAL-INTEROP.md) and [current repository status](../../../STATUS.md). The new sidecar reuses the normalized model and existing GLB metadata. Named parts, declarations and exact geometry references remain traceable to accepted `.ok` source and pinned dependencies.

The demonstration uses a separate derivative of the frozen keyed-rack fixture, changes `first.fingers["middle"].length` from 0.65 m to 0.75 m, and checks invalid edits, unaffected siblings, regeneration and explicit unsupported-feature behavior. Actual checks, evidence and publication are recorded when executed; the intended scope alone is not a completion claim.

C209 job/0.2 retained-result compatibility and all further C201 native admission work are deferred. Frozen C201 protocol files, C199/C200 evidence and closed schedules, C208 timing failure/separate pass, earlier source identities and inherited regression failures remain unchanged. Only the main integrator may publish the exact reviewed candidate under the current lease.
