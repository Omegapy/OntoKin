**Scope:** Experimental source `0.14` / `keyed-transform-0.1`, explicit Agent/0.14 and recorded GLB/0.14, with unchanged immutable bundle/files `0.2`. Complete feature release and full-product acceptance remain false.

OntoKin's [GOAL](../../../GOAL.md) is a language primarily for AI agents to construct, inspect, revise and reuse meaningful 3D objects and behavior through authoritative `.ok` source. It preserves cardinality, canonical ASCII key order, the 256-entry bound and all inherited type/unit/frame and construction limits.
