## What this adds

Each public API/CLI invocation freshly executes unchanged C221 authority admission. The new checker then opens and holds the envelope and six member descriptors, rejects symlinks/nonregular files/inode aliases, reads bounded bytes, and rechecks descriptors and directory entries before returning. Parsing rejects duplicate keys, nonfinite numbers, malformed Unicode and declared depth/count/size violations.

The envelope binds geometry, materials, normals, poses, semantics and a required declared corner map. It joins every part's source node, mesh, element ID, definition ID and source path. It compares material/normal/map geometry-byte references with the bytes actually read, checks normal copies against geometry, and validates complete raw/source corner inventories and the declared winding. Geometry/material definitions that their original schemas do not contain are explicitly authority-derived joins. Labels remain untrusted declarations.

The report retains complete identities and map rows, actual member bindings, dependency results, semantic provenance/capability declarations, decoded retained-file lengths/hashes and explicit pending component outcomes. A refusal preserves already inspected member bindings and identifies the reached stage and stable reason. Original component source and numerical limits remain unchanged.
