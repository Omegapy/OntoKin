# Hosted subagent comparison

The Pro coordinator delegates each route to a fresh coding subagent through the session's native delegation tool. A participant writes editable source, calls its assigned exporter, reads the GLB back and submits its files. The coordinator retains the inputs and validates both deliveries. The current workflow requires a host with delegation, a native Blender installation and an OntoKin checkout. Qwen, llama.cpp, model downloads and third-party inference credentials are historical C181 replay dependencies only.

## Run the public rehearsal

1. Restore the checkout using the start-here instructions. Locate Blender 4.5.3 LTS and confirm that its glTF export operator starts. Stage two separate writable directories. Put a copy of the matching starter, the common task and the public checker in each directory. Keep the originals read-only where practical.
2. Before the first assignment, record hashes of the common task, checker and both starter directories, the tool versions, the model selection and the available telemetry. Record which tool and file boundaries the host actually enforces.
3. Call the native spawn tool twice with fresh context. For this host the option is `fork_turns="none"`. Leave model and reasoning overrides unset for both. Use the same task text, success conditions, allowed assistance and submission interface. Supply only the relevant route name, paths, tool invocation and runtime location with each assignment. Use new workers after changes to the task or practice method.
4. Keep coordinator and reviewer roles out of the repair work. Log the dispatch and completion of each route, interventions and failed attempts. The planned rejection is a public check against the unrepaired part. A child then corrects the source and submits through the actual hosted interface. Mark any coached trial as assisted and repeat with fresh children before declaring an unaided pass.
5. Preserve both baseline and repaired GLBs, editable files, measurements and participant logs. As coordinator, run the independent checker on each baseline and repair. Rebuild from each submitted source in a fresh directory and remeasure. If either route fails, record the failing stage and repeat public qualification after correcting the cause.

The shared host used for this rehearsal exposes the same filesystem and tool registry to the children. Separate prompts and assigned directories reduce accidental crossover. They provide no security boundary. Route results here establish whether the delegated editing workflow runs. They do not measure general superiority or token efficiency.

## Register the next unseen comparison

Before opening a new case, the coordinator should do the following.

- Select a genuinely new matched repair. Keep its materials out of this public ZIP. Keep the C181 rotary assignment available for regression only. Freeze the common objective, equivalent native starters, allowed documentation, acceptance thresholds, scoring rubric, attempt order or independent scheduling, stop rules and output requirements in a dated, hashed card before dispatch.
- Require the same model selection and reasoning settings for both routes. Record any available actual worker model or backend ID. If the host cannot attest a specific model build, describe the arms as matched by requested configuration. Preserve the exact prompts and task hashes.
- Test the boundary from the *actual hosted participant interface*. Each worker must be unable to see the other route, answers, evaluator, coordinator files or external services through any enabled tool. A VM around a shell is insufficient if the same child can invoke unrestricted file, browser, connector or delegation tools. Allow only a route-scoped execution channel, disable further delegation for participants, and test denied reads, outbound network, deadline cancellation and final file custody. If this is unavailable, keep the task sealed and continue with public rehearsals.
- Freeze an enforceable equal time budget, maximum attempts and intervention rules. Register a rule for repeated failed actions, collection of partial work and the behavior of any in-flight action at cutoff. Token use is optional for the hosted design. Record exact input, cached and output tokens with their accounting semantics only if auditable per-worker receipts exist. Store unavailable values as null. An observed token count alone does not enforce a cap. If the research question requires a fixed token ceiling, wait for a controller that can enforce it for both routes.
- Have the coordinator seal and hash both submissions before giving masked copies to an independent assessor. Retain the route-to-label map separately and lock scores before unmasking. Remove route-revealing metadata where this preserves the scored geometry. If source inspection reveals a route, record which portion was unblinded.
- Report completion, deviations from the independent measurement, export validity, source reproducibility, retries and interventions. Report time only from instrumented comparable windows. One repair supplies evidence for that case. A decision about broader language value needs multiple preregistered unseen tasks.
