## Basis

`delta >= S + 114*E + A`

Here `delta` is candidate minus ordinary comparison-only operation cost, `S` is added setup cost, `E` counts omitted ordinary one-unit comparisons, and `A` counts first admissions. Setup and admissions are nonnegative. Consequently, M1 strictly increases this operation total whenever `E > 0`.

This is a source-derived lower bound under the proposed accounting rules. It is neither an observed runtime tick count nor a complete gate cost. It does not establish that every alternative versioned model is impossible.
