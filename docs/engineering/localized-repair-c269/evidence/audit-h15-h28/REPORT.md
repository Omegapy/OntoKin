## Four remaining gaps

**H16 — computed SiteRef.** C265's
`test_h16_unsupported_endpoint_expression_forms` supplies undeclared
`self.ref` and `site(self.pivot)` without a declared SiteRef producer. The
retained run records `MALFORMED` for the former and unsupported form for the
latter; the test allows either code. Neither establishes the frozen clause
for an otherwise valid declared/computed SiteRef. Static resolver inspection
does not substitute for an executed control. This does not establish a
product defect.

**H20 — independent invariance evidence.** C265's source geometry/action
mutations compare against `field_projection(observer(original))`. The
independent baseline and original before/after comparison support baseline
and length behavior, but do not supply an independently constructed expected
projection for every changed geometry/action control. C261 independently
mutates actual plural `follows` and `boundary_states` in separate raw controls.
C266 bundles owner/geometry/transform mutations in a binding-only test.
C267's bundled comparison control writes singular `follow`. No isolated
comparison mutations of actual owner, plural follows and motion fields were
identified. Raw observation and object binding cannot be relabeled complete
hinge comparison. H28's narrower nontrivial-pose nonclaim is independently
supported.

**H22 — missing import digest.** Actual stale dependency bytes, stale pins,
repinned sources with stale artifacts, missing/wrong source/program scalars
and every consumed repeated mapping leaf are exercised. No isolated deletion
of the source import digest was identified. General truncation controls and
mandatory-digest parsing are not counted as that executed subcase. The
partial verdict is conservative under the control plan's explicit
stale/missing/contradictory wording.

**H24 — excessive sites.** The source control admits exactly 128 hinges and
256 distinct referenced sites. Separate inputs demonstrably reach inherited
C257 object/token/depth/definition guards and the source hinge guard. No
retained input with more than 256 distinct referenced sites was identified.
The 128-hinge cap and two endpoints per hinge logically bound the site count;
that mathematical redundancy is not an executed excessive-site control. A
later bounded task may explicitly assess that redundancy or add an actual
multi-limit refusal control. This audit does neither.
