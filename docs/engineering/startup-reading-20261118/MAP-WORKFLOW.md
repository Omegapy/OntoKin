## Coordination rules moved from AGENTS

PROTOCOL section 7 now carries the original detailed lease and parallel-work
rules, rather than duplicating them in both required files: distinct owner
identities and scoped branches, observed bases, ownership handoffs, protected
shared status/release/pinned files, nonoverlapping branch progress under another
lease, coordinated overlaps, reviewable exact evidence, serialized conditional
integration, honored existing expiry, meaningful renewal only, and unknown-write
reconciliation before reacquisition. Its adopted OK-ENG-009 link preserves the
complete history-retention and stacked-PR procedure; it does not turn an archive
index into a product-development base or permit deleting unfinished work.

Each substantial branch checkpoint/reviewable PR must explicitly record actual
code/head SHA, changed files, executed tests with observed results, CI/evidence,
known failures, unmet gates and the exact handoff action. PROTOCOL section 7
retains this actual-evidence obligation separately from planned scope/checks.
