# Startup reading compression

The owner requests shorter startup files without loss of meaning. Current operative rules stay in the mandatory read set; detailed historical records remain available on demand. This folder records the original bytes, obligation mappings, measured reductions, review and verification. It is not another required startup document.

`before/` mirrors the original paths with a `.txt` suffix. These are historical snapshots at `ee509d5d7ce3a4c0fb61cdb9e2668575e3af370d`, not current instructions. Relative references inside a snapshot resolve at its original repository path and revision. `PRESERVATION.json` binds every archived byte and original Git blob. No existing preservation hash or historical failure is rewritten.
