# Reach runtime integration attempts

These are actual focused development runs for the adopted
OK-LANG-006/0.1.0 implementation. They are not a complete reach release or a
claim that the full product goal is complete. Failed attempts remain preserved.
Every test process ran in an exclusive executor window with the other workers
paused. No hosted workflow was dispatched or retried.

## Attempt 001

[The report](attempt001/report.json) identifies combined local implementation
`c6e1c34b281df2c54963720121d60889bd9fb198`, tree
`7bf2df620e1611b39ba6a2e8b025af03579ec33a`, and CPython 3.12.14 on Linux.
All 1,046 tracked file hashes and the source Git identity stayed unchanged.
The retained runner executed 79 test methods across twelve modules without
skipping an incomplete delivery test into a passing result.

The 26 numeric, eight delivery-arithmetic and six protocol-isolation methods
passed. Source binding passed six of its seven methods; a newly written
compatibility probe had omitted mandatory scene gravity. Most lifecycle and
Agent tests could not proceed because the reach snapshot's direct JSON
measurement encountered a typed `LoftSection` inside inherited geometry.
The actual exception and every test log are retained alongside the report.

Source checkpoint `efea2738f4048d5dd1fd405b9bcade853b1689de` fixes the snapshot
boundary by applying the inherited bounded typed conversion to the complete
result, preserving all geometry and exact entry/byte/depth limits. Combined
commit `c67866f682a8757456c972f596449aee8b02c64d` applies that source change.

## Attempt 002

[The retry report](attempt002/report.json) identifies implementation
`f5e21456d8843d9a0beb9c608525b13ab1f13368`, tree
`6a9fb801db25f63d1c674c3c00bb17b5a1f99b52`. It executes the 39 affected methods;
already passing numeric/arithmetic/protocol-isolation modules are not relabeled
as rerun. Every tracked input and Git identity again stayed unchanged.

The snapshot conversion fixes the initial blocker. Actual normal Agent
creation, before/after inspection, complete persisted projection, failed-prefix
recovery, named-action identity, discovery, JSONL transport and frozen-schema
checks now pass. LP01, LP03, LP04 and LP05 pass their actual protocol sequences.
LP04 includes the real 128-action complete response, measured N/N−1 limits and
the final response guard. Cancellation and competing acceptance/run publication
also execute successfully. These results cover only the named implemented
paths, not pending artifact delivery or the full release.

The retry remains **failed**. Longer lifecycle and multi-arm Agent operations
exhaust the shared 100,000-operation budget. The newly authored older-profile
probe also needs a positive scene duration; the frozen source corpus is not
changed to repair that test. The [measured operation costs](attempt002/operation-costs.json)
show roughly 8,400–9,300 numeric units for a fresh lifecycle observation,
29,000 units for initial admission plus the complete after-state, and additional
work at pause/handoff boundaries. L01 reaches the inherited limit before its
1.5-second before-state; L02 and L03 also exhaust it before completing their
fixed observations. The cost probe changed neither budgets nor implementation,
and its tracked inputs remained unchanged.

The next fix reduces actual repeated constant-transform, validation and pose
arithmetic while preserving cancellation, constituent accounting, exact
admission and the same request budget. The complete numerical source bounds
and independent reference must remain valid after optimization.
