# Reach runtime integration attempts

These are actual focused development runs for the adopted
OK-LANG-006/0.1.0 implementation. They are not a complete reach release or a
claim that the full product goal is complete. Failed attempts remain preserved.
Every test process ran in an exclusive executor window with the other workers
paused. No hosted workflow was dispatched or retried.

## Attempt 001

[The report](attempt001/report.json) identifies combined local implementation
`c6e1c34b281df2c54963720121d60889bd9fb198`, tree
`7bf2df620e1611b39ba6a2e8b025af03579ec33a`, and CPython 3.12.14 on Linux.
All 1,046 tracked file hashes and the source Git identity stayed unchanged.
The retained runner executed 79 test methods across twelve modules without
skipping an incomplete delivery test into a passing result.

The 26 numeric, eight delivery-arithmetic and six protocol-isolation methods
passed. Source binding passed six of its seven methods; a newly written
compatibility probe had omitted mandatory scene gravity. Most lifecycle and
Agent tests could not proceed because the reach snapshot's direct JSON
measurement encountered a typed `LoftSection` inside inherited geometry.
The actual exception and every test log are retained alongside the report.

Source checkpoint `efea2738f4048d5dd1fd405b9bcade853b1689de` fixes the snapshot
boundary by applying the inherited bounded typed conversion to the complete
result, preserving all geometry and exact entry/byte/depth limits. Combined
commit `c67866f682a8757456c972f596449aee8b02c64d` applies that source change.
