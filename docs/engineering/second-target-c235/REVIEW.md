## Independent oracle and findings

The reviewer decoded the original pinned GLB and C214 payload with a separate
standard-library implementation, without importing OntoKin, exporter or checker
code to construct the oracle. It verified both authority documents, all eight
original input byte hashes/modes and all 3,024 original source-corner normal
records.

The synthetic observation rearranged the same retained fixture through reversed
part/triangle order, cyclic triangle rotations, the predeclared winding reversal,
split vertices, reversed vertex numbering and repeated descriptive names. Its
expected map came from the original index stream before any checker import.
It covers the same 18 parts, 7,800 triangles and **23,400 corners**; it is not a
new source fixture or native observation.

Eighteen scenarios checked every report row, all **70,200 component outcomes**,
all 18 part summaries and every exceeding-corner record. Raw keys, source
keys/vertices, original binary32 bytes, preserved vectors, exact component
flags, deltas, angles and overflow indicators agreed with the independent
oracle. A separate half-angle formula checked the implementation's cross/dot
angular calculation.

Normal-only changes altered the exact geometry-byte identity while retaining
the complete map digest. False good copies over bad raw normals, swapped keys,
type differences and signed-zero copy mismatches were refused. Positive signed
zero retained its raw sign and measured zero error. Normals did not influence
correspondence.

The unchanged inclusive **0.000002 = 1/500000** limit used exact represented-value
rational differences before normalization. Adjacent binary64 values bracketed
the boundary at zero and nonzero source components; private checks covered
exact equality and infinitesimal overruns. Magnitude-only errors failed even
when angular error was zero. Opposite and orthogonal directions measured 180
and 90 degrees. Subnormal and huge finite vectors remained measurable, with
magnitude overflow explicitly null and flagged. No new shading tolerance was
introduced.

Structural failures left comparison `NOT_RUN`. Admissible measured failure
retained all 23,400 rows under `FAIL_STRICT_NORMAL_LIMIT`, including a mixed-loss
case with one changed corner in each part. Actual CLI pass, measured failure,
malformed-input and argument-error behavior matched the [contract](CONTRACT.md).
Stale authority/geometry/map claims, incomplete or malformed observations,
unsafe paths and a geometry change after C222 checking were also refused.

replayed, and this review establishes neither Godot behavior nor R07 or release
