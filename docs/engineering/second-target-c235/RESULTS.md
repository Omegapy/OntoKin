## What the component checks

A surface normal is a direction used for shading. C235 compares all **23,400
instance corners and 70,200 components** of the unchanged 18-part C210 fixture
with the exact C214 source directions. The [contract](CONTRACT.md) versions this
finite comparison separately; the [README](README.md) gives its invocation.

Every public check freshly admits the original authority through C221 and
obtains C222's complete geometry correspondence. Part identity, positions and
the predeclared winding rule select that map; normals never select a match.
The normal document binds the exact geometry bytes and complete map digest.
Every copied corner normal must canonically equal its bound raw geometry array
value, including type and signed zero. A clean copy cannot conceal a changed
raw normal.

C235 rereads the pinned C214 payload and GLB, checks the original normal bytes
against the NORMAL accessors, and retains each raw vector beside its source
binary32 bytes. The unchanged inclusive **0.000002 = 1/500000** component gate
uses exact rational differences of the represented numbers. It applies no
component normalization, extra epsilon, observation rounding or new tolerance.
Angular measurements are diagnostic only. Every measured corner, every
exceeded component and all 18 per-part summaries remain visible.

Structural rejection produces `FAIL_CLOSED` with comparison `NOT_RUN`. A valid
observation that exceeds the strict limit produces `FAIL_STRICT_NORMAL_LIMIT`
and retains all 23,400 measured rows. A numerical pass establishes these CPU
checks on untrusted observations; it does not establish native fidelity.
