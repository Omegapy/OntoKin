# Compression decisions

The owner requested smaller startup Markdown without information loss and protected README files. Prior compression already removed much ordinary prose. This phase preserves exact originals, shortens complete operative instructions, consolidates duplication through mandatory sources, and keeps all existing README files unchanged.

## Reversible dictionary experiment

A standard-library reader encoded exact Git source bytes with a visible nonrecursive glossary. Its23 focused tests and 10 independent check groups passed after recorded corrections. On pinned source `2c800160880a496aa3c06770b66ae9caab246adb`, direct startup was 16,622 o200k_base tokens; the default packet plus entrypoint used 16,485 (0.824% less). A wider dictionary used 16,402 (1.324% less); a measurement-only token-aware probe used 16,195 (2.569% less). Counts include glossary/framing/metadata and the already-read entrypoint.

The helper is deferred from active startup: its added machinery does not justify the measured saving. Exact experimental bytes are retained in experiments/ with hashes; implementation/review records retain the tested original paths and failed attempts. No tokenizer/runtime dependency or new tool is installed in the repository workflow.

## Navigation-only metadata

STATUS contains 50 empty HTML anchors naming historical links. All 50 remain unchanged in the file. START now explicitly permits omitting only those complete empty-anchor lines from routine model readout; history/link work must load them. No prose, headings, instructions, state or evidence reference may be omitted. This is a disclosed reading change, not a claim that the filtered readout contains every original byte. Full-file metrics and effective-startup metrics are reported separately.

## Preservation and limits

Exact before-images and source hashes preserve all 11 edited documents; 284 README files and C268 task/evidence remain unchanged. Independent review checks normative meaning, including conditions, exceptions and claim strength. Byte preservation is mechanically verified; semantic review is not a formal theorem about all possible interpretations. Measurements use tiktoken 0.12.0/o200k_base, not a live ChatGPT context counter. Reduced reading does not remove conversation limits or create automatic compaction.
