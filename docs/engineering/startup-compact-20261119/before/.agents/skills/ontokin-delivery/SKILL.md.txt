# Deliver one OntoKin milestone

Use the already-required [AGENTS](../../../AGENTS.md), [ROLE](../../../ROLE.md),
[PROTOCOL](../../../docs/workflow/PROTOCOL.md) and
[HANDOFF](../../../docs/workflow/HANDOFF.md). Load missing applicable text in full;
do not reread unchanged copies.

## Define and implement the work

Apply PROTOCOL sections 3–4: requirement coverage, plan, owned scope and bounded
workers. Return design defects to the Director; never silently reduce acceptance.

## Verify the candidate

Apply PROTOCOL section 5 and AGENTS' change-specific checks. Resolve mandatory
review findings using actual current artifacts and evidence.

## Integrate and verify actual main

Apply PROTOCOL section 7 and its adopted integration policy. Keep integration,
release acceptance and unresolved gates distinct.

## Close and hand off

Evaluate [ontokin-learning](../ontokin-learning/SKILL.md), recording capture or
skip rationale. Verify the published checkpoint, branch/ownership disposition
and HANDOFF's saved ZIP/external receipt. Stop after the declared phase;
merged code or documentation cannot replace outstanding delivery.
