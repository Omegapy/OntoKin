## The remaining semantic blocker

The [literal source](evidence/canonical-history-source.ok) contains a spinning
parent and hinge, release followed by world-X torque at one second, and an
unrelated later force event. The following public calls use the same immutable
source and its original admitted work, under 100,000 operations / 30,000 ms:

| Successful prefix `"16384"`, immediately followed by prefix `"1"` on the same model/work | Refused before with `OKL-E-FRAME / incoming_axis`; incoming Z component exactly `2^-96` | 40,969 cumulative |

There is no private cache inspection, plan injection, callback substitution or
source mutation between the calls. The [actual closing-pin results](evidence/canonical-history-public-results.json)
and [independent derivation](evidence/canonical-history-independent-analysis.md)
show that the inherited 96-bit and 192-bit spin plans produce distinct
canonical angular vectors: zero versus a nonzero `2^-96` component. Both plans satisfy their finite guards at the short clock.

Exact-zero admission, preservation of the history-dependent inherited route,
common-clock repeatability and a source-only independent reader cannot all hold
for this witness. Selecting whichever plan yields zero, treating an interval
containing zero as a proof, or accepting a small residual would change the
adopted semantics. C091 therefore preserves the contradiction and holds the
candidate. The [C092 proposal](C092-NEXT-TASK-PROPOSAL.md)
is the concrete next task: adopt and publish one deterministic source/elapsed
plan rule, then implement it independently in producer and reader.
