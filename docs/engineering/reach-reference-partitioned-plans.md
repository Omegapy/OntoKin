## The repeated calculation

The existing source-plan entry declined an entire state if any root had become
dynamic. In original P16, releasing `payload` at two seconds therefore disabled
the prescribed formulas for every rig carrier too. Each subsequent key
reconstructed those source recipes and their shared ancestry through the
ordinary recursive walker. The payload's dynamic motion does not alter the
source authority of the other roots.

The new optional split is available only to an outer complete source batch.
It captures the same bounded global relationship receipts, then identifies
which requested ancestries terminate at a prescribed root and which terminate
at a dynamic root. Prescribed nodes use the existing interval plan. Dynamic
nodes use the existing full source walker, including their dynamic anchor,
force, spin and attachment calculations. Every requested carrier remains in
the result. An unsupported prescribed recipe still declines the whole optional
plan; this change does not introduce a second mathematical implementation of
an unsupported source law.

Context-free requests, nested requests and the private centered reader retain
their preceding dynamic-state refusal. In particular, this cut does not
assert that a moving or uncertain root has a centered unit quaternion.

## Source proof of the split

The plan retains the full ordered target tuple. Its new `remaining` tuple names
only requested carriers whose captured ancestry reaches a dynamic root. The
existing small-versus-broad composition choice therefore still depends on
the original request size, not a reduced subset.

Construction uses the original first-visit graph walk and copied source
relation receipts. A dynamic root contributes a small native receipt binding
its object membership and exact source mode. A site below that root contributes
its actual owner receipt. A joint or following edge below it retains the same
global endpoint receipt that the plan already captures. The dynamic marker
propagates only along these source relations. It cannot propagate from an
unproved numerical result or a sampled zero rate.

Every global joint and following relation is still captured, including
inactive grips and relations outside the requested ancestry. Collection
counts, active grips, map owners, phase/state selection and all source operand
receipts retain their final complete-batch admission. Redirecting an unused
edge, changing an owner, or changing a captured root's mode rejects the
transaction. A selected subset cannot hide a new incoming relation.

Ordinary remainder markers count toward the original 128-frame bound even
though they do not produce plan nodes. The other sufficient bounds remain
64 targets, 64 objects, 128 sites, 32 joints, 32 following relations, eight
active grips and 32 staged cursors. The same batch still retains at most
16 plans and 1,024 receipts; all numeric values and cursors use the original
256-entry cache. A plan contains source recipes and path names, never a second
numeric pose map or a history of completed samples.

## Evaluation and complete fallback

The private partial result is a source-plan descriptor. It holds no completed
numeric frames. The ordinary remainder executes first in the original
walker's fresh frame map. It cannot obtain a parent pose from the prescribed
plan. The independent interval plan runs only after that ordinary calculation
completes, and its fresh frames are merged only after successful admission.
Both subsets can share `world`; any other overlap with a prescribed node means
the live ordinary route departed from the captured root partition and rejects
the optional result.

If the optional domain declines, the same original walker finishes every
missing requested target. Its already computed dynamic frames remain in that
map. No work counter, budget or numeric cache is reset, and the dynamic branch
is not calculated a second time merely because the optional prescribed plan
declined. Any attempted but unaccepted plan arithmetic remains charged.
Original arithmetic failures and callback exceptions are never caught or
converted into this fallback.

After the rig becomes stationary, the caller can request only the dynamic
payload while reusing independently proved stationary endpoint comparisons.
An empty prescribed node tuple still retains its source classification in
the same bounded batch. It needs no new numeric plan evaluation. Earlier
full plans remain available for the existing stationary-source query.
Dynamic remainder targets contribute only an explicit false stationarity
flag, even when a sampled velocity is zero. Positive stationarity still
requires the existing actual-and-ideal source proof for every prescribed node.

## Callback and finite-domain boundary

The mixed request requires the native independent arithmetic, 128-bit grid,
original native tick dispatch, unchanged arithmetic/source owners and full
32,768-bit operand domain. Its clock is bound by native numerator and
denominator fields. An already active post-tick observer declines this optional
split rather than replacing another reader's scope.

During the ordinary remainder and following plan evaluation, a private scope
uses the existing `_Arithmetic.tick` observer. The original tick captures that
observer before invoking the original caller check, then invokes it only after
the callback returns normally. No callback is replaced and no arithmetic work
charge is removed or added by the observer. Ownership, clock, precision and
dispatch departures reject before subsequent arithmetic can consume them.
The scope restores its observer only while it still owns that field, so a
callback's replacement is not silently erased.

A narrowed operand cap latches optional ineligibility for the current request,
including when another original callback later restores the cap. The observer
does not raise an optional restart at that boundary: the original operation
continues to its original scalar and prospective finite-product guards. Its
actual resource exception or callback exception must escape with its identity.
Only successful ordinary completion followed by a latched optional decline
chooses the complete same-work fallback. No tolerance or finite allowance is
broadened to make that fallback succeed.

The batch depth remains nested while this mixed request runs. Reentrant
readers retain ordinary per-request source admission; they cannot acquire
the outer deferred proof. Existing cursor-owner checks reject an attempt to
overwrite a nested reader's completed value, and batch failure deletes only
still-owned cursor writes. Ordinary cache eviction remains legitimate and
requires an independent reseed under the unchanged 64-step ceiling.
