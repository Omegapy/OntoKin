capture and the existing C238 envelope/C239 CPU checks. [CONTRACT.md](CONTRACT.md)
predeclares immutable inputs, loader choices, native identity, raw capture before
metadata writes, provenance, complete member projection and later process limits.
It does not implement or authorize a native run.

[Static evidence](evidence/STATIC-PREFLIGHT.json) confirms the installed candidate
still matches the exact C220 bytes. Build lineage, rendering and enforceable
execution prerequisites remain unresolved. [Source review](evidence/MAPPING-LIFETIME-REVIEW.md)
also identifies an upstream mesh-node replacement risk for the intended loader
lookup; it is an inference from pinned upstream source, not a demonstrated bug
in the installed candidate.

No numerical limits or historical results change. [Next task](NEXT-TASK.md)
selects one zero-start mapping/capture design step. Integration, independent
review and final handoff outcomes are recorded by the root coordinator.
