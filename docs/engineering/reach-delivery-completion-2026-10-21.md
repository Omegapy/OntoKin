## Changes supporting this result

The implementation removes repeated exact work: guarded axis normalization and
grid projection, exact zero terms, sample-local physical observations,
immutable source metadata, bounded JSON text blocks and independent reference
pose traversal. It retains per-action authority, lifecycle, outcome, identity
and complete logical output accounting. Independent caches stay bounded by
their original capacities and share the caller's work/cancellation context.

History validation compares complete bounded identity subtrees using native
equality after checking every nested container shape and scalar type. Each
subtree visits at most 64 occurrences. Larger records, numerical enclosures and
mismatches follow the precise recursive validator. Identical numerical vector
proofs use complete keys containing every actual exact ratio, independent
interval endpoint, dimensional allowance and impulse-rounding policy. Every
input is guarded before lookup. Quaternion checks retain their antipodal norm
predicate; an exact point equality proves zero error directly. Fresh mutable
history records are never shared.

The independent source mesh optimization is separately measured in
[its validation record](reach-source-mesh-reuse.md): P23's 64 identical surface
constructions become one immutable construction while every occurrence retains
its identity, aggregate vertices and actual accessor/PBR validation. Its node
construction saves 22,168 operations with identical complete node data. It does
not by itself establish a complete P23 recording pass.
