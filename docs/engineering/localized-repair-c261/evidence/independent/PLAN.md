# C261 independent raw-artifact controls

Scope: only `observe_glb_hinges(raw)`. Expectations come from the frozen C260 contract and direct independent decoding of the original before/after GLB bytes. No source observer, product compiler, exporter, semantic sidecar or candidate result supplies an expected value.

The reviewer will compare every returned joint field and actual JSON pointer with the independently decoded input; verify the result remains explicitly untrusted; and vary artifact bytes without original hash admission. Controls cover six signed axes, exact numeric boundaries, ordered limits/initial, whole-row shape and identity uniqueness, text/identity caps, object/source-map claims, byte/chunk/JSON structure, duplicate keys, depth and size limits, and numeric lexeme/exponent limits.

Valid different values, reversed signed basis axes, row/node reordering, changed source/provenance labels and changed joint counts are raw observations, not comparison successes. Same-object endpoint truth, source membership, repeated source agreement, canonical source units and historical admission remain outside this raw interface.

The frozen 28 H groups will be mapped to selected raw-interface subcases only. No whole-group or complete hinge-component qualification is claimed. All failed attempts and exact implementation/input hashes will be retained in compact procedural evidence; copied GLBs are regenerated from the original bytes by the retained script rather than stored repeatedly.
