# C084 keyed merge contract

The [adoption](ADOPTION.md) and [grammar supplement](ontokin-keyed-merge.ebnf) define bounded pure merging for explicit source 0.17 / keyed-merge-0.1, Agent/0.17 and recorded GLB/0.17. Two exactly typed immutable keyed inputs form a canonical disjoint union; any shared key is refused, including equal values.

The [acceptance inventory](acceptance.json) points to [independently authored source cases](../../../examples/keyed-merge/README.md), no-merge .16 controls, exact source locations, provenance order and actual Agent workflow requirements. Reviewed adoption and the published input freeze precede runtime changes. Implementation, executed validation, integration and release acceptance remain separate facts.

Earlier semantics, ordinary defaults, unchanged gates and all [GOAL](../../../GOAL.md) domains remain in force.
