# C083 keyed filtering contract

The [adoption](ADOPTION.md) and [grammar supplement](ontokin-keyed-filter.ebnf)
define bounded pure filtering for explicit source 0.16 / keyed-filter-0.1,
Agent/0.16 and recorded GLB/0.16. A Boolean predicate selects original keyed
entries without renaming keys or converting values. Existing map and reduction
operations compose with filtering under the same inherited work limits.

The [acceptance inventory](acceptance.json) points to the independently authored
[source corpus](../../../examples/keyed-filter/README.md), exact .15 controls,
source spans, membership expectations and actual Agent workflow requirements.
Adoption/input publication precedes runtime edits. The coordinator records the
final independent review and exact freeze manifest separately.

Implementation, executed validation, integration and complete feature release
remain separate claims. Original release gates, execution defaults and all
[GOAL](../../../GOAL.md) domains retain their meanings.
