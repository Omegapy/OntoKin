# Experimental keyed pair Agent/0.18

This interface decision accompanies the [C085 language contract](../keyed-zip-v0.1/ADOPTION.md). It becomes effective only after independent review and publication of the exact input freeze. This preparation document does not claim runtime support or completed validation.

The explicit interface is `ontokin.agent/0.18`, for source `0.18` / `keyed-zip-0.1` and recorded destination `ontokin.glb/0.18`. Bundle/files remain `0.2`. Earlier bindings and CLI/Python defaults retain their meanings. Pairing requires equal complete key sets in two exactly typed immutable keyed inputs; one pure expression derives every output in canonical ASCII order.

The twelve operations retain their existing request shapes:

| Operation | Existing responsibility |
| --- | --- |
| `discover` | Report this experimental profile, bounded exact-key pairing and current host authority. |
| `create` | Admit an exact offline source/asset bundle atomically. |
| `edit` | Apply revision-bound UTF-8 source/asset changes with exact preconditions and rollback. |
| `validate` | Check an identified accepted or candidate program at the requested level. |
| `inspect` | Return bounded detached source, state and original contributor provenance. |
| `surface.mesh_page` | Page the selected revision's bounded source-derived mesh. |
| `evaluate` | Record supported motion under current authority. |
| `reset` | Preserve inherited reset and immutable revision/run meanings. |
| `export` | Publish a complete verified artifact for the named recorded destination. |
| `artifact` | Retrieve bounded exact artifact bytes with pinned identity. |
| `status` | Reconcile durable request/run status, including an unknown outcome. |
| `cancel` | Apply actual cooperative cancellation without partial accepted publication. |

The .18 store filename is `keyed-zip-program-agent.sqlite3`; its schema identity is `ontokin.keyed-zip-program-agent-store/0.1`. Keep the 8,388,608-byte request envelope, current complete-request ledger, ordinary 100,000-operation / 30,000-ms defaults, independent host ceilings and reducing caller caps. Every inherited parser, value, image, geometry, cursor and response limit remains in force.

The only new inspection families are `derived_zips` for derived property values and `input_zips` for generated occurrences. The language contract fixes their complete ten-field schema, aggregate normalization, contributor locations and ordering. These fields confer no writable synthetic identity. Repairs use original source/member identities, current revisions and exact UTF-8 preconditions.

A missing partner is `OKL-E-ID` with `operation`, lowest mismatched ASCII `key`, and `missing_side`. Its primary source token is the missing-side operand; the related token is the present-side operand. No body runs and no partial output is accepted after key-set disagreement. Every input/body boundary is exact after type/alias resolution. The named `keyed_zip_keyset` and `keyed_zip_iteration` checkpoints must run at their actual stages.

The frozen workflow must exercise all operations, stale revisions/cursors, bounded complete source-unit reads with pagination, plus asset/artifact byte slices, actual JSON response exhaustion, cancellation, reopen/retry, changed-payload refusal and interrupted publication. It must include two textured occurrences with separate dimension/material libraries, a repair of only the first, an invalid missing-partner edit with exact rollback, an unchanged sibling/library/assets, surviving identities and unrelated recorded marker motion. Compare each complete artifact to an independently authored .17 control with complete BIN and raw JSON/framing inspection and the narrowly enumerated metadata allowances. Preserve raw requests/responses and durable stores.

Implementation, executed evidence, integration and complete feature release remain separate. Earlier retained failures and every [GOAL](../../../GOAL.md) domain remain visible.
