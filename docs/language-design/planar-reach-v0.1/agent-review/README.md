## Reproduction

Use a verification-only environment with `jsonschema==4.26.0` and
`referencing==0.37.0`; the runtime's standard-library dependency policy is
unchanged. From the repository root:

```bash
python docs/language-design/planar-reach-v0.1/author_schema_drafts.py
python docs/language-design/planar-reach-v0.1/agent-review/check_schemas.py --output /tmp/reach-schema-check-fresh.json
```

The checker refuses to overwrite a previous report. When the separately owned
supplements have been integrated, add
`--supplements-dir docs/language-design/planar-reach-v0.1/draft2-supplements`.
This additionally validates the 51 recorded expected sides and 86 complete
source-recording projections. Without that dependency the report explicitly
marks supplementary shape checks pending.

The checker loads only the schema generator, standard-library JSON counter,
JSON Schema verifier and exact source/document bytes. It opens no Agent store,
creates no SQLite database, compiles/evaluates no source, builds/decodes no GLB,
and runs no full regression, archive or browser operation. All references
resolve from the declared local schema resources; no network retrieval is used.

The checks cover all seven metaschemas and deterministic generated bytes,
inherited reference closure, every original corpus member hash, the exact 12
request operations, declared request-only differences, candidate/historical
identity shapes, unrun/constructed/run contexts, five lifecycles with four
current goal outcomes, terminal/current rate distinctions, negative partial
claims and states, diagnostic taxonomy in each response location, both-side
history and release completeness, explicit direct clock conversion, complete
numeric-bound bases and a synthetic full 128-action envelope.
