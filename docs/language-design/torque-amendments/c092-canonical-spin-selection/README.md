# C092: deterministic canonical spin selection

**Proposal identity:** `OK-LANG-022-CANONICAL-SPIN/0.1.0`  
**State:** proposed amendment; implementation is blocked until the separate adoption receipt records independent approval and actual publication readback  
**Date:** November 3, 2026 (America/Denver)

The same immutable C091 program accepts a world-X torque at one second when
evaluated fresh and rejects it after a successful request at 16,384 seconds.
An inherited phase plan changes the released canonical angular velocity from
exact zero to a vector with Z component `2^-96`. Exact axis admission, request
repeatability and independent reconstruction cannot all use that history as an
unstated input.

This amendment selects the first certifying precision stage from the actual
constant angular velocity and actual elapsed time of each source point
operation. It preserves the controlled arithmetic, exact axis predicate,
physical anchors, earlier bindings, resource ceilings and original frozen
expectations. Continuous certificates use the ideal continuous law and a
uniform controlled-kernel discrepancy; they do not assume a rounded point map
is continuous.
